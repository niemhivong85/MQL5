========================================================================
           ✅ ĐÃ THÊM: SESSION FILTER (Lọc Phiên Giao Dịch)
========================================================================

TÍNH NĂNG MỚI:
--------------
EA giờ đây có thể LỌC PHIÊN GIAO DỊCH!

✅ CHỈ VÀO LỆNH trong phiên bạn chọn
✅ VẪN QUẢN LÝ lệnh cũ ngoài phiên
✅ 4 phiên: Asian, London, New York, Sydney
✅ Có thể chọn nhiều phiên cùng lúc
✅ Tự động check weekend

========================================================================
                         CÁC PHIÊN
========================================================================

1. ASIAN (Tokyo):    00:00-09:00 GMT  →  07:00-16:00 VN
2. LONDON (Âu):      08:00-17:00 GMT  →  15:00-00:00 VN  
3. NEW YORK (Mỹ):    13:00-22:00 GMT  →  20:00-05:00 VN
4. SYDNEY (Úc):      22:00-07:00 GMT  →  05:00-14:00 VN

⭐ OVERLAP TỐT NHẤT: London + NY = 13:00-17:00 GMT (20:00-00:00 VN)

========================================================================
                    CẤU HÌNH TRONG EA
========================================================================

Right-click EA → Properties → Inputs:

┌─────────────────────────────────────────┐
│ Trading Session Filter                  │
├─────────────────────────────────────────┤
│ Enable_Session_Filter = true      ✅    │
│ Broker_GMT_Offset = 2                   │
│ Trade_Asian_Session = false       ❌    │
│ Trade_London_Session = true       ✅    │
│ Trade_NY_Session = true           ✅    │
│ Trade_Sydney_Session = false      ❌    │
│ Allow_Weekend_Trading = false     ❌    │
└─────────────────────────────────────────┘

========================================================================
                      VÍ DỤ SETUP
========================================================================

1. TRADE PHIÊN ÂU + MỸ (PHỔ BIẾN NHẤT):
   ✅ Trade_London_Session = true
   ✅ Trade_NY_Session = true
   → Vào lệnh: 08:00-22:00 GMT (15:00-05:00 VN)
   → Best for: EUR/USD, GBP/USD
   → Overlap 13:00-17:00 GMT = TỐT NHẤT

2. CHỈ TRADE PHIÊN ÂU:
   ✅ Trade_London_Session = true
   ❌ Others = false
   → Vào lệnh: 08:00-17:00 GMT (15:00-00:00 VN)
   → Biến động cao nhất

3. TRADE PHIÊN Á + ÚC (Range Trading):
   ✅ Trade_Asian_Session = true
   ✅ Trade_Sydney_Session = true
   → Vào lệnh: 22:00-09:00 GMT
   → Biến động thấp, phù hợp range

4. TRADE 24/7 (KHÔNG LỌC):
   ❌ Enable_Session_Filter = false
   → Vào lệnh: Mọi lúc
